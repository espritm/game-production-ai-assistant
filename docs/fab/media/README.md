# Media provenance and reproduction

Run scripts/render-fab-media.py with Python + Pillow on the development machine. End users do not need Python. Outputs are an original 128 px plugin icon, 512 px publisher icon, SVG master and three 1920 x 1080 PNG gallery images. media-manifest.json records dimensions and sizes.

01 and 03 are original procedural feature graphics. 02 embeds a real current Unreal Editor capture saved from the explicitly selected GPAA_Manual window on 8 November 2026. Only the plugin panel is cropped into the marketing layout; its contents are not replaced or generated. The capture shows an existing owner's conversation, not a new request. No key is visible. The raw source capture is retained here for reproducibility but is not part of the upload dossier.

The UI automation could capture the selected window but did not reliably change tabs, so this dossier uses the genuine existing prompt view and does not claim extra search/settings captures. The SVG/PNG icon is a proposed product identity included for owner review, not an Epic or OpenAI logo. No third-party font file or demo-project asset is redistributed.
